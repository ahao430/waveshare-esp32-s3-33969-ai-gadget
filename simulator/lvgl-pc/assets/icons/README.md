# 应用图标（用户自备素材）

放入本目录后重启模拟器即可生效；文件缺失时桌面自动回退到符号占位。

| 文件名 | 应用 |
|--------|------|
| sub.png      | 订阅 |
| weather.png  | 天气 |
| pomodoro.png | 番茄钟（gpt-image 生成） |
| settings.png | 设置 |
| music.png    | 音乐 |

要求：正方形 PNG（推荐 88×88，任意正方形尺寸均可——磁贴按实际尺寸自适应缩放）；
全出血构图（四周留边会被裁掉一半视觉，介意的话画满画布）；
不需要自己做圆角（渲染侧统一 26px 圆角裁切）。
角色类头像（大肥鱼/小智/Muse）在 assets/avatars/ 下（88×88）。

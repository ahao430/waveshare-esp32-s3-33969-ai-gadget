## 待对齐差异（按优先级）

1. **彩色 App 磁贴图标**：概念稿每 App 一个彩色圆角图标（音乐红/订阅青/
   ZCode 深蓝/天气蓝/服务器紫/设置灰蓝）+ 三 AI 用**形象头像**作图标。
   当前实现是统一紫蓝符号。→ 磁贴图标裁自概念稿或重生成。
2. **波浪渐变背景**：桌面底部波浪曲线 + 渐变光晕。
   当前是纯色。→ 可用 LVGL canvas 预渲染一张背景图。
3. **对话页顶栏**：概念稿顶栏有**角色头像 + 在线状态点**（● 在线）。
   当前只有标题。→ 顶栏加 44px 头像图 + 绿点。
4. **中央麦克风大按钮**：概念稿底部是**中央圆形麦克风按钮**（蓝底白麦）
   + 左右波形 + 右下键盘小按钮。当前是整宽 PTT 长条。→ 重排底部交互区。
5. **监控卡四列布局**：概念稿每服务器卡含 CPU/内存/磁盘/网络 四列
   （当前两列：CPU/MEM）+ 彩色服务器 icon + 在线 pill。
   → Bridge 数据已有网络字段（net_up/down），UI 补列。
6. **订阅页布局**：概念稿 5h 环显示"剩余时长"（h）+ 右侧"本周额度
   x/y h"独立卡 + "手动加热"火焰按钮。当前环形显示百分比+整宽周条。
   → 数据层已有秒数（window_seconds），UI 换算展示。

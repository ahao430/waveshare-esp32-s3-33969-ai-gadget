   纵向渐变 + 顶部径向光晕 + 底部两层正弦波；4×4 Bayer 抖动消 RGB565 色带。
3. ✅ **对话页顶栏**：44px 圆形头像 + 绿点在线状态（上一轮完成）。
4. ✅ **中央麦克风大按钮**：96px 圆形 PTT + 左右波形（上一轮完成）。

5. ✅ **监控卡四列布局**：CPU/内存/磁盘/网络 四列 + 紫色服务器 icon +
   在线/离线胶囊 pill；数据层补 disk_pct/net_up/down（Bridge 已有字段）。
6. ✅ **订阅页布局**：5h 环显示**剩余 x.xh**（window_seconds 换算）+
   右侧"本周额度 x.x / 168 h"卡 + 橙色"手动预热"按钮（二次确认模态）+
   "刷新数据"按钮；weekly reset_at 解析修复（legacy 字段覆盖 bug）。

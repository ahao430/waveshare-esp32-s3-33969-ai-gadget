# Companion Sequence Assets v1

目标设备：Waveshare ESP32-S3-Touch-AMOLED-2.16（SKU 33969，480×480）

## 本包内容

- `concept_atlases/`：三位角色的表情/状态概念总览。
- `spritesheets/`：角色动作图集，供进一步裁切和逐帧整理。
- `references/`：Muse 参考图（若原始上传文件在当前工作区可用）。
- `spec/manifest.json`：统一动作状态清单。

## 第一版建议动作（每位角色共用状态接口）

| ID | 中文 | 播放方式 |
|---|---|---|
| idle | 待机 | 循环 |
| listening | 聆听 | 循环 |
| thinking | 思考 | 循环 |
| speaking | 说话 | 循环 |
| happy | 开心 | 播放一次 |

## 重要限制

**本包是角色设计与动作图集素材，不是已经完成的逐帧动画资源包。**

图集中的同一动作小图是概念姿态/表情，不保证像素级一致、帧间连续、尺寸统一或网格对齐。因此不能直接按等分网格切图后就当作可播放动画，也没有声称已经生成 GIF、LVGL C 数组或设备端 `.anim` 文件。

要形成真正可播放的序列帧，下一步需逐个动作制作严格统一画布、透明背景、固定角色锚点、等尺寸连续帧（建议先做 6–8 帧/动作），再逐帧检查、裁切、去背景/Alpha 修复，最后转 RGB565 + Alpha 或索引色格式并做设备内存/帧率测试。

## 设备侧建议

- Flash：只放基础动作和启动必需资源。
- TF：放扩展动作包。
- PSRAM：只缓存当前动作的少量帧。
- 原始 WebM/GIF：留在电脑端归档，不直接交给 ESP32 解码。
